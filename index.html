Safety and Security First

Built with robust modern isolation principles. Internet Explorative keeps your data private while giving you full compatibility with today's web landscape without bloating your machine.

  • Modern Chromium 140.0* security patches
  • Lightweight PyQt6 interface wrapper
  • Protected by DuckDuckGo tracking protection
  • Zero telemetry or invasive background trackers

*The browser identifies itself as Chromium 120 even though PyQt 6.11 is based on Chromium 140.

Distraction-Free Experience

Enjoy a clean, clutter-free web with built-in adblocking that removes aggressive ads and keeps browsing fast.

Me, You, Anybody

Seamlessly switch users with built-in profile support. Multiple people can use the exact same app on the same machine while keeping their personal browsing sessions, bookmarks, and histories completely separate.

  • Instant profile switching
  • Separate data isolation per user
  • Shared app experience for family or team members

Your Browser, Your Way

Tailor the interface to fit your exact workflow and aesthetic. Personalize accent colors to match your taste, configure custom homepages, and choose your preferred search engine with complete ease.

  • Customizable accent color themes
  • Flexible homepage configuration
  • Choice of preferred default search engines

Old. But new.

Built to look like Internet Explorer, Internet Explorative bridges the gap between classic aesthetics and modern standards, allowing legacy operating systems like macOS Mojave to run today's web apps smoothly and efficiently.

  • Built to look like classic Internet Explorer
  • Optimized for legacy macOS (Mojave & up)
  • Extremely low memory footprint

Experience the Real IE 11 Browser Experience

Powered by advanced built-in emulation features, Internet Explorative tricks websites into thinking you're running authentic Internet Explorer 11, giving you full legacy site compatibility effortlessly.

  • Advanced user-agent and engine emulation
  • Websites recognize the environment as IE 11
  • Seamless compatibility with legacy web apps
