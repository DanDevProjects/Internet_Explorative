# Security Policy

## Supported Versions

Currently, only **v11.x** is supported. I highly recommend using 11.x.

| Version | Supported          |
| ------- | ------------------ |
| 11.x    | :white_check_mark: |
| 1.0 beta| :x:                |

## Reporting a Vulnerability
To report a vulnerability, go to the **General** or **Ideas** discussion to report a bug, safely issues, or anything else you would like to fix.

## Issues
Due to older PyQt5 versions on the 1.0 
release (beta), there is a high chance you
will experience frequent bugs, privacy issues, or website compatibility issues.
