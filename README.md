# Internet Explorative

**WARNING:** This project is vibe-coded. Some bugs may still exist.

### About Internet Explorative
Internet Explorative is a lightweight, secure and powerful web browser designed to mimic the Internet Explorer user interface added with many modern features such as an **adblocker**. Built on python and powered by PyQt6 with Chromium 140.0.7339.225. It only uses about less than 500 MB of RAM and the app itself is only less than 200 KB. It has all the features you will possibly need, the only downside is that you **cannot** install chrome extensions, while you can port them through a Chromium Extension file. This might appear on the next few releases, but they might not work correctly.

### Announcement

Internet Explorative is going Mac-first because Windows already have the original built-in. Windows versions still exist, but you'll have to wait for one more major release. For Windows Users in a rush, Please go download **rinFox** on https://github.com/travy-patty/rinfox/releases/tag/Release, or you can use WSL 2 to emulate the Mac app onto Windows, but that may not work all the time or even work.

### Setting up
With Internet Explorative, there is no setup after installing. There is only a welcome screen (adding in the next release), after that, you just browse. No login, no signup, no data tracking privacy agreements and stuff. My project wouldn't spy you and I don't have the resources to store all your history. Why do I even *Want* to spy you? go ask Google, the browser's default search. you can also make it DuckDuckGo.
